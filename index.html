02 Building with agents

A lot of my time lately goes into building with and around Claude Code: deterministic, LLM-driven applications that automate parts of my own engineering workflow.

The organizing idea is that the model does the part that needs judgment and nothing else. Sequencing, state, and retries stay in ordinary code, where they can be tested. State is event-sourced and owned by the application rather than held in a context window, so a run is inspectable and resumable after the fact, and the same input produces the same path through the system every time.

  1. 2025 – 2026

    Autonomous delivery pipeline

    Design and implementation

    Takes a work item from card to pull request to deploy to CI without a human driving each hop. An event-sourced state machine owns the transitions and decides what happens next; the agent works inside a single step and never gets to choose the step after it. Failures land as events, which makes a stuck run something you can read rather than something you have to re-run to understand.
